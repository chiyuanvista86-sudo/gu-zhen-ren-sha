蛊真人题材的单人策略卡牌同人游戏。「升仙对决」与共用凡蛊手牌系统已融合为唯一玩法：炼蛊成招、交易谋局、经营寿元，再渡劫入仙。

应用显示名已改为「蛊道争仙」。仓库地址、APK文件名、Android应用ID及发布签名继续沿用，方便旧APK覆盖升级。v3只继承人物解锁进度，规则不兼容的旧进行中对局需要重新开始；网页版和APK各自保存进度。卸载会删除本地数据。

- 普通身份局、模式切换、旧引擎及旧设计导出已删除。
- 保留四蛊位、炼制、维护、升炼、拆解、两组件杀招，以及雷、火、蚀元、风四种周期灾劫。
- 新增寿蛊、紫晶舍利、通天、神念、搜魂、书虫、铭心、东窗八种共用手牌，共64张实体；加入市场、订单、神念和铭心位。
- 人物为方源、白凝冰、黑楼兰、太白云生，各有天赋、两个专属凡蛊组件、专属杀招和成仙解锁的仙蛊技能。
- 十种通用凡蛊组件、六项通用杀招全部开放，开局选五种组件与两种杀招。仙蛊不再作为通用配方或手牌。
- 账号只解锁人物；元石、仙元、寿元、真元和修为全部在本局获得或重置。

## 一局如何进行

双方五转初阶，30体魄、8寿元、3元石、4真元，免费本命蛊；手牌各5张并保证寿蛊。每轮各3行动，交替执行，每轮交换先手。

第二轮起，轮初减1寿元、补满真元、领取补给、摸2牌。凡人每轮+2元石（上限10），仙人每轮+3仙元（上限6），旧元石封存不转换。真元用于凡蛊和共用手牌；元石/仙元用于对应阶段的经营、交易与炼制，仙技只付仙元。

基础攻伐不需手牌：1行动、2真元造成2伤害。攻击蛊、攻击杀招、攻击仙技与基础攻伐共用每轮一次机会；疗伤每轮一次，与攻伐二选一。主动护盾保护人物和蛊虫，护劫屏障只抵灾劫。

普通修行1行动、3元石、1寿元，升一个五转小境界；舍利可节约修行费用，但共用每轮升境一次。巅峰以2行动、4元石、2寿元宣告突破并清零真元；下一整轮末承受6点地劫，存活后成仙。成仙后每三轮周期渡劫，强度递增，不回血、不重置场面。

体魄归零立即败北。寿元归零可在本轮用寿蛊补救，轮末仍为零则败北；双方同轮末败北为平局。

## 操作和修改

点己方蛊位，再选蛊方炼制；催动支付真元。杀招先参悟，再组合两只不同、尚可用的蛊虫发动。点敌蛊可指定拆除组件。

点手牌查看并使用：书虫付费后选牌；东窗先付定金再查询货源；通天点选市场牌/订单并可搭配出售旧手牌；搜魂先由对手决定是否用神念抵抗，再随机查看。

- [CULTIVATION.md](./CULTIVATION.md)：实际完整规则与设计清单。
- [CULTIVATION.json](./CULTIVATION.json)：结构化修改表。
- [CHANGELOG.md](./CHANGELOG.md)：版本变更。

反馈编号：N人物、G01—G08手牌、U组件、K杀招。游戏内可下载完整清单与修改表；编辑清单不会自动改变规则。战报导出隐藏对手手牌、未获得的私人信息及未知牌序。

## 开发和验证

需要 Node.js 22+。

```sh
npm ci
npm run dev
npm run check
```

检查包括规则测试、32局完整AI对战、每一步实体守恒及存档合法性、TypeScript、离线嵌入校验。构建产出单文件 `dist/index.html` 及规则清单。

GitHub Actions 编译并签名Android APK，检查版本、签名和内置资产，标签发布在断网模拟器上检查开局、旋转、保存恢复及单模式界面。APK不申请网络或存储权限，文件导出使用系统选择器。

当前为可玩原型，数值尚待真人试玩；未提供联网对战、云同步或七至九转。人物、卡牌效果和统一五转起点为竞技改编，不代表原著全部设定。未进行实体手机/平板测试。
