# 蛊真人杀 · 五域争锋

蛊真人题材的单人策略卡牌同人游戏，布局参考身份类卡牌桌游。你控制一名蛊师，与四名 AI 进行完整五人身份对战。

## 直接游玩

- 在线版：https://chiyuanvista86-sudo.github.io/gu-zhen-ren-sha/
- 下载版：在仓库 Releases 下载 `gu-zhen-ren-sha-web.zip`，解压后双击 `index.html`。所有脚本、样式和写意立绘均已内嵌，不需要网络、账号或安装程序。
- 手机浏览器可玩；手牌较多时横向滑动手牌区域。桌面端提供完整战局记录面板。

## 首版内容

- 盟主、护法、魔修、独行者四种身份，五人配置为 1 / 1 / 2 / 1。可自行选择身份。
- 方源、白凝冰、黑楼兰、凤九歌、太白云生、古月方正、影无邪、星宿八名角色及对应技能。
- 93 张蛊牌，13 类效果：月刃、移形蛊、生机草、元石、斗蛊、盗天手、离散蛊、兽潮、万羽齐发、酒虫及三种装备。
- 距离和攻击范围、装备替换、天蓬蛊红色判定、轮流斗蛊、群体响应、濒死自动自救、击杀奖励、误杀惩罚和身份结算。
- 自动存档、胜场统计、暂停 AI、三档速度、可选音效、角色图鉴、规则说明、JSON 战报导出。

## 规则速览

盟主先行动，随后按座位顺序轮流行动。摸两张牌后进入出牌阶段；点击手牌，按提示选择目标并确认。结束回合时，若手牌数超过当前体力，必须选择多余的牌弃置。月刃每回合限一次，基础攻击范围为一。

其他角色使用攻击或群体蛊时，玩家可选择响应牌，或承受伤害。斗蛊双方轮流打出月刃。体力降至零时，角色自动使用自己手中的生机草；不能自救则阵亡。没有其他角色救援流程。

盟主与护法击败所有魔修、独行者获胜。魔修击败盟主获胜；如果盟主阵亡时仅剩独行者，则独行者获胜。独行者需要成为唯一幸存者。

AI 按自身身份、公开身份及公开出牌记录选择目标，不读取其他角色的手牌。未揭晓身份存在误判，AI 不保证最优策略。当前不含联网、无懈可击、延时锦囊、其他角色救援，角色技能为本作独立设计的简化规则，并非官方规则。

## 本地开发

需要 Node.js 22 或更高版本。

```sh
npm ci
npm run dev
```

```sh
npm test       # 规则与多种子整局模拟
npm run build # TypeScript 检查 + 单文件生产构建
npm run check # 完整验证
```

`dist/index.html` 是可独立分发的完整游戏文件。Vite 开发服务器默认仅监听 `127.0.0.1`。

## GitHub 自动构建

本仓库独立使用自己的工作流、Pages 地址和构建产物，不修改其他仓库。

- 推送到 `main`：测试、编译、上传 Actions 构建产物，并发布 GitHub Pages。
- 推送 `v*` 标签：测试、编译并创建带离线游戏压缩包的 Release。
- Pull request：仅测试和编译。
- Pages 需要在仓库设置中将构建来源设为 GitHub Actions。

## 目录

`src/engine.ts`：独立规则引擎与 AI；`src/data.ts`：角色、身份、卡牌数据；`src/main.tsx`：交互界面；`src/Art.tsx`：原创 SVG 写意插画；`src/engine.test.ts`：规则与完整对局测试。
